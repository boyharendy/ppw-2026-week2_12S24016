  3. Implementasi Berstandar Framework & CSS: Memadukan Bootstrap 5 dengan custom properties secara modular.
  4. Audit Aksesibilitas & Uji Lintas Perangkat: Verifikasi rasio kontras warna, navigasi keyboard, dan responsivitas.
  5. Deployment & Dokumentasi: Rilis publik via GitHub Pages lengkap dengan changelog komparasi.

KUSKAS — Keuangan Sakti Kas

Latar Belakang & Solusi Masalah

KUSKAS dirancang untuk mengatasi kebiasaan pencatatan finansial manual yang lambat dan rentan terlupakan. Melalui integrasi kecerdasan buatan Gemini AI, pengguna cukup merekam ucapan suara pengeluaran (misal: "Beli bensin 50 ribu di SPBU"), sistem secara otomatis mengurai nominal, kategori, dan tanggal transaksi secara real-time.

Arsitektur & Fitur Unggulan

  • AI Voice Categorization: Pemrosesan bahasa alami untuk mendeteksi entitas belanja dan nominal.
  • Sinkronisasi Multi-Platform: Backend Supabase Realtime menghubungkan aplikasi mobile Flutter dengan panel admin React.
  • Otentikasi Aman: Fitur Login QR Code cepat untuk akses desktop tanpa perlu mengetik kredensial berulang.
Flutter / Dart Laravel 11 React.js Supabase Google Gemini AI

KOCARI — E-Commerce Trust Aggregator

Latar Belakang & Solusi Masalah

Konsumen daring sering kesulitan membandingkan harga asli serta membedakan penjual terpercaya dengan toko fiktif di berbagai marketplace online. KOCARI hadir sebagai mesin pencari independen yang mengumpulkan data produk sekaligus mengkalkulasi indeks skor reputasi toko secara transparan.

Arsitektur & Fitur Unggulan

  • Automated Data Scraping: Pipeline ekstraksi harga, rating, dan riwayat transaksi secara terstruktur.
  • Trust Scoring Algorithm: Algoritma pembobotan ulasan pelanggan dan rasio keberhasilan pesanan.
  • Responsive Comparison Grid: Tampilan perbandingan matriks produk yang rapi di layar ponsel maupun desktop.
JavaScript (ES6+) Node.js Web Scraping Bootstrap 5 Data Normalization
Buka Repositori GitHub ↗

Aether Weather — Glassmorphism App

Latar Belakang & Solusi Masalah

Aether Weather menggabungkan akurasi data meteorologi dengan seni visual antarmuka modern. Dirancang dengan efek Glassmorphism bergradasi dinamis yang menyesuaikan warna suasana langit (cerah, mendung, hujan, badai) serta tetap mempertahankan rasio kontras teks agar terbaca dengan nyaman.

Arsitektur & Fitur Unggulan

  • Adaptive Glassmorphism: Penggunaan CSS backdrop-filter dan variable tokens untuk efek visual kaca tembus pandang.
  • OpenWeather API: Penyajian suhu, kelembaban, kecepatan angin, indeks UV, dan prakiraan 5 hari secara real-time.
  • Aksesibilitas Digital: Kepatuhan WCAG 2.2 AA dengan mode kontras tinggi dan dukungan navigasi keyboard penuh.
React.js Glassmorphism CSS OpenWeather API WCAG 2.2 AA
