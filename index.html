Halo, saya Boy Harendy Simamora

Mahasiswa Sistem Informasi • Spesialisasi Full-Stack Web, Data Analytics & Accessible UI

Saya mahasiswa Program Studi Sistem Informasi di Institut Teknologi Del dengan ketertarikan mendalam pada rekayasa web modern, arsitektur backend, analisis data terintegrasi, dan antarmuka inklusif. Proyek portofolio ini merepresentasikan penguasaan tata letak semantik, integrasi framework Bootstrap 5, dan kustomisasi variabel CSS tingkat lanjut sesuai standar WCAG 2.2 Level AA.

Ajukan Konsultasi Lihat Portofolio

Kompetensi Inti & Teknologi Unggulan:

  • Front-End & Frameworks: Bootstrap 5.3, React.js, Next.js, JavaScript (ES6+), TypeScript, Tailwind CSS, HTML5 Semantik, dan CSS3 Modern.
  • Back-End & Bahasa Pemrograman: Java, C, Python, Dart/Flutter, RESTful API, dan arsitektur microservices ringan.
  • Basis Data & Cloud: MySQL / SQL Relasional, Supabase, Firebase Realtime Database, dan optimasi pemodelan query.
  • Kualitas & Standar: Git Version Control, GitHub Pages, Aksesibilitas WCAG 2.2 AA, dan W3C Standards.

Tahapan Standar Pengerjaan Proyek:

  1. Analisis Kebutuhan & Pemodelan Sistem: Mengkaji PRD, spesifikasi bisnis, dan persona pengguna.
  2. Perancangan Antarmuka & Wireframe: Menyusun tata letak responsif mobile-first dan komponen reusable.
  3. Implementasi Berstandar Framework & CSS: Memadukan Bootstrap 5 dengan custom properties secara modular.
  4. Audit Aksesibilitas & Uji Lintas Perangkat: Verifikasi rasio kontras warna, navigasi keyboard, dan responsivitas.
  5. Deployment & Dokumentasi: Rilis publik via GitHub Pages lengkap dengan changelog komparasi.
