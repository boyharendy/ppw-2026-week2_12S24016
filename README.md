## ✨ Fitur & Standar Desain

- **HTML5 Semantik:** Penggunaan tag semantik (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`) tanpa *wrapper* yang tidak perlu.
- **CSS3 Modern & Responsif:** Tata letak fleksibel menggunakan CSS Grid dan Flexbox dengan pendekatan *mobile-first*.
- **Aksesibilitas Digital (WCAG 2.2 AA):** Kontras warna optimal (rasio 60-30-10), navigasi keyboard penuh, *skip link*, dan teks alternatif gambar.
- **Formulir Layanan Interaktif:** Validasi data murni *native* HTML5 untuk pengajuan konsultasi/kerja sama.
